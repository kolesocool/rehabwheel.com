# Website-wide 200-point review

- Added the photo gallery canonical URL.
- Kept the icon reference out of search results.
- Added missing descriptions.
- Hardened external-tab links.
- Standardized asynchronous image decoding.
- Refreshed shared stylesheet references across all reviewed pages.
- Enabled shared menu behavior where its script was missing.

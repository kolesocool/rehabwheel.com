- Historical Git versions and client caches may still expose old demo code; private beta access needs authentication or restricted hosting.
- The FormSubmit email endpoint is reused from existing website forms. Deliverability and provider account activation require live confirmation.
- The waitlist collects only optional name and required email/consent; no health or disability information should be requested.
- Do not represent search ranking, search impressions, subscriptions or indexed results as proven without production measurements.

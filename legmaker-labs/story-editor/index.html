Participant story draft editor

This tool creates a local JSON draft for a reviewed GitHub publication. It is not a secure account, a medical-record system, or a direct-upload CMS. Nothing is uploaded by this page.

Do not enter medical diagnoses, personal contact information, or consent documents. All submissions require human editorial review.

To publish, append the downloaded object to the stories array in assets/labs-stories.json through a reviewed GitHub pull request. No story is public until the PR is merged.
